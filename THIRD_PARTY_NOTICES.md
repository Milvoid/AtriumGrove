# Third-party components

Atrium Grove is an independent implementation. This task assigns no license to the project's original source. Dependency licenses do not license the original project as a whole.

Dependencies are pinned in `pnpm-lock.yaml`. Consult each installed dependency's upstream license text; package metadata does not replace those license texts.

Codex interface schemas in `packages/runtime-codex/fixtures/0.157.1` were generated by the locally installed OpenAI Codex CLI 0.157.1. Codex is a separately installed executable; its applicable upstream licenses remain in effect.

Claude Agent SDK is an installed dependency. Claude Code is a separately installed executable using the user's existing authentication. Anthropic's applicable SDK and service terms continue to apply.

LCU is an optional external adapter from `amontlabs/lcu`, development reference commit `45e5a917e768edddb5c1b6fe737b7cdddc9cbebe`, version 0.10.0, under its MIT license. Its development checkout and runtime installation are ignored under `.tools/`. The signed OpenAI application, CUA runtime, Node runtime and code-mode host remain in their original application bundle and are not redistributed or relicensed by Atrium Grove.

Native integration requires the relevant vendor software and account access. CI uses fake runtimes without vendor authentication or desktop permissions.
